How My Working Hub works

A step-by-step breakdown of the full pipeline

1
Record audio

Go to Recordings and choose your source — Mic (your microphone only), App (system audio only), or Both (default, captures everything). Hit Record to start; hit Stop when done. The file is saved locally as a .wav and appears instantly in History.

You can also import existing audio files (WAV, MP3, M4A, MP4…) via the ↑ Import button in History.
2
Transcribe Local · faster-whisper

Click Transcribe on any recording card. faster-whisper runs entirely on your machine — no audio ever leaves your computer. It automatically detects the language and produces a timestamped raw transcript. The first run downloads the model weights (~1.5 GB for medium) and caches them.

Change the model by setting WHISPER_MODEL=large-v3 in your environment for higher accuracy, or tiny for speed.
3
Correction API · GPT-4o-mini

Right after transcription, the raw Whisper output is sent to GPT-4o-mini, which fixes only clear mishearings — wrong homophones, garbled words. It never rephrases or restructures. The result is saved as the Corrected transcript. You can compare both versions side-by-side in the transcript viewer.

4
AI Chat API · DeepSeek

The AI Chat page lets you ask questions across all your recordings. The assistant can search through transcripts to find relevant moments, people, decisions, or topics. It responds in Spanish by default.

Try asking: "What was decided about X?" or "Which meetings mentioned Y?"
Services overview
Transcription faster-whisper 100% local Free — runs on your CPU/GPU
Correction OpenAI GPT-4o-mini API ~$0.00015 / 1K tokens
AI Chat DeepSeek API Very low cost
